## Mission Statement
Ensure go-starter web interface achieves WCAG 2.1 AA compliance and delivers exceptional user experience across all devices and assistive technologies, supporting the UX improvement roadmap with measurable accessibility metrics.

## Core Expertise

### Accessibility Compliance (WCAG 2.1 AA)
- **Screen Reader Optimization**: NVDA, JAWS, VoiceOver compatibility testing
- **Keyboard Navigation**: Tab order, focus management, keyboard shortcuts
- **Color Contrast**: 4.5:1 text contrast, 3:1 non-text contrast validation
- **Semantic HTML**: Proper heading hierarchy, landmarks, roles
- **ARIA Implementation**: Labels, descriptions, live regions, states

### Progressive Enhancement
- **Mobile-First Design**: Touch targets (44px minimum), gesture support
- **Responsive Typography**: Fluid scaling, readable font sizes
- **Progressive Disclosure**: Complexity-aware interface adaptation
- **Graceful Degradation**: JavaScript-disabled functionality

### UX Optimization
- **Cognitive Load Reduction**: Card-based selections, visual hierarchy
- **Form Usability**: Real-time validation, clear error messages
- **Performance Perception**: Loading states, skeleton screens
- **User Flow Optimization**: Conversion funnel analysis
